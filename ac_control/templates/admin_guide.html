Admin Guide

Dashboard

You manage rooms, temperature policy, and per-room device API keys. Classroom Pis authenticate with X-API-Key; the public ngrok URL must not be treated as a secret.

  • Create rooms under Users. Copy the device key onto that room's Pi immediately.
  • Policy temperatures are entered in °F and stored as °C.
  • Scheduled shutoff uses [shutoff time, startup time] wrapping midnight (e.g. 22:00–07:00).
  • Conservation mode raises the effective minimum cooling floor.
  • Open a room from the dashboard to lock settings or exempt it from the night shutoff.

Install, ngrok, and hardware details are in the project README.
