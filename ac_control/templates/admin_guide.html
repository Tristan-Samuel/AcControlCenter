Admin Guide

Dashboard

You manage rooms, temperature policy, and ESP32 device keys. Classroom boards authenticate with X-API-Key. MAC addresses identify hardware; they are not a secret.

  • Create rooms under Users. Assign an unassigned ESP32 MAC, or copy a device key into WiFiManager.
  • ESP32s must use the Pi’s LAN IP as SERVER_URL, even if admins reach the dashboard through a school subdomain.
  • A physical remote “ON” restores that room’s last setpoint. Change the setpoint on the room page.
  • Door open can auto-shutoff, buzz, or both. Window reeds can be added later on the same board.
  • Policy temperatures are entered in °F and stored as °C.
  • Scheduled shutoff uses [shutoff time, startup time] wrapping midnight (e.g. 22:00–07:00).

Install, reverse proxy, and wiring details are in the project README.
